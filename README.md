# 🔴 Laravel Pokédex

Une application web simple et moderne développée avec Laravel permettant de répertorier, consulter et gérer des Pokémons.

---

## 🚀 Prérequis

Avant de commencer, assurez-vous d'avoir installé sur votre machine :

- **PHP** >= 8.2 (avec extensions `pdo`, `mbstring`, `openssl`, etc.)
- **Composer**
- **Node.js** & **npm** (pour la compilation des assets)
- **MySQL** ou **PostgreSQL** / **SQLite**
